# AP Computer Science Principles 国际考备考手册

面向 AP CSP 国际考的**自编中文备考手册**，覆盖 Big Idea 1–5 与 Create Performance Task 全六章。

**在线访问：** https://candy297.github.io/apcsp-handbook/

## 内容结构

| 章节 | 主题 | 选择题内权重 | 页内题量 |
| --- | --- | --- | --- |
| Big Idea 1 | 创造性开发（Creative Development） | 10–13% | 52 题 |
| Big Idea 2 | 数据（Data） | 17–22% | 58 题 |
| Big Idea 3 | 算法与编程（Algorithms and Programming） | 30–35% | 34 题 |
| Big Idea 4 | 计算机系统与网络（Computer Systems and Networks） | 11–15% | 36 题 |
| Big Idea 5 | 计算的影响（Impact of Computing） | 21–26% | 60 题 |
| Create Performance Task | 创造性性能任务（总分 30%） | 30% | 23 张答题卡 |

## 内容特色

- **考点梳理**：按官方 CED（Course and Exam Description）逐考点展开，配代码示例与易错点提示。
- **可作答选择题**：共 240 道英文原题，页面内直接点选、即时判对错并显示解析。
- **真题与样题解析**：收录 2025–2026 三套国际考真题及 CED 官方样题，逐题给出中文解析与考点标注。
- **代码选项排版**：选项为代码时分行显示并严格缩进，符合官方 Exam Reference Sheet 的书写风格。
- **Quick Reference**（Big Idea 3 第 12 节）：2020 官方 Exam Reference Sheet 全文收录（赋值、算术、关系与布尔、选择、迭代、列表、过程、机器人指令）。
- **CPT 交互卡**：Create Performance Task 章节采用「英文题干 + 点击展开参考回答」形式，含 6 行评分逐行攻略与 5 分范文。

## 考试结构提要

- **Section I · 选择题**：70 题，占总分 **70%**，Bluebook 数字化作答，可用官方 Exam Reference Sheet。
- **Section II · Create Performance Task**：占总分 **30%**，含课堂提交组件与考试日 4 道书面回答。
- **合成分（满分 100）** = 选择题答对题数（out of 70）× 1 + CPT 六个评分行（各 out of 1）× 5。
