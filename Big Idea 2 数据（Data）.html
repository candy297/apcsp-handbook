      Topic 2.1 Binary Numbers（二进制数）

      知识点梳理（DAT-1.A / 1.B / 1.C）

      （1）bit 与数据表示（DAT-1.A）

      • Bit = binary digit，只能是 0 或 1；1 byte = 8 bits。
      • 计算机最底层只用 bit 存一切数据：数字、字符、颜色、声音、指令——同一串 bit 在不同上下文中表示不同类型的数据（DAT-1.A.7 高频考点：01000001 既是十进制 65，也可以是字符 "A"，也可以是一个颜色分量）。
      • Abstraction（抽象）：把 bits 分组以表示数字、字符、颜色等，就是"用抽象降低复杂度"。用数字数据近似真实世界的模拟数据，也是抽象。
      • 模拟数据（analog data）：连续平滑变化的值（音调、音量、画的颜色、赛跑者的位置）。数字化近似的方法是采样（sampling）：以固定时间间隔测量模拟信号，每个测量值（sample）用一串 bit 存储。采样题标准答案句式："measured at regular intervals… each measurement stored as a sequence of bits"。

      （2）二进制 ↔ 十进制（DAT-1.C）

      • 位权：从最右位起，位权为 2⁰, 2¹, 2², …（位置编号从 0 开始）。
      • 二进制 → 十进制：按位权求和。例：1011 = 8 + 0 + 2 + 1 = 11。
      • 十进制 → 二进制：减最大的 2 的幂，或短除法取余。例：46 = 32 + 8 + 4 + 2 = 101110。
      • 比较大小：先转十进制再比，或位数多的（无前导零）更大。

      必背 2 的幂表（考场心算核心）：

      2⁰2¹2²2³2⁴2⁵2⁶2⁷2⁸2⁹2¹⁰2¹⁶2³²2⁶⁴
      1248163264128256512102465536≈43亿≈1.8×10¹⁹

      （3）n 个 bit 能表示多少个值（最高频计算题）

      • n bits → 2ⁿ 种不同序列，能表示的非负整数范围是 0 ~ 2ⁿ − 1。
      • 反过来：要区分 N 个不同对象，需要满足 2ⁿ ≥ N 的最小 n。
      • 200 个字符 → 2⁷=128 不够，2⁸=256 够 → 8 bits。
      • 75~100 件商品 → 2⁶=64 不够，2⁷=128 够 → 7 bits。
      • 0~10 的整数（11 个值）→ 2³=8 不够，2⁴=16 够 → 4 bits。
      • 位数增加带来的"倍数"关系：从 m bits 增加到 n bits，可表示的值数量变为原来的 2ⁿ⁻ᵐ 倍。
      • 6→7 bits：2 倍；32→64 bits（计数器）：2³² 倍；IPv4 32-bit → IPv6 128-bit：2⁹⁶ 倍。
      • 末尾追加 k 个 0 → 数值 ×2ᵏ（与十进制末尾加 0 ×10 同理）：追加 1 个 0 = ×2；追加 3 个 0 = ×8。

      （4）溢出与舍入（DAT-1.B，几乎每年必考）

      • Overflow 溢出：整数用固定 bit 数存储，超出最大可表示值（n bits 无符号上限 2ⁿ−1）就溢出。典型症状：大数相加后结果错误甚至变成负数（播放量 200 万变成七位数负数）。
      • Round-off 舍入误差：实数（浮点数）用固定 bit 存储，只能近似。典型症状：5.0/3.0 = 1.6666666667、(0.5 − 0.4) − 0.1 ≠ 0。
      • 注意：考试参考表定义的编程语言中，整数大小只受内存限制（无溢出概念的抽象）；但题目若明确说"uses a fixed number of bits"，就按溢出考。
      • 8-bit 无符号整数：范围 0~255。90 + 150 = 240 ≤ 255 → 不溢出（2026 真题反套路）；200 + 60 = 260 > 255 → 溢出。

      重难点

      重难点 1：三类计算题模板（必须秒杀）

      题型模板例
      "minimum number of bits"找最小 n 使 2ⁿ ≥ N200 人 ID → 8 bits
      "用 n bits 能表示多少/范围"2ⁿ 个值，0 ~ 2ⁿ−14 bits → 16 个值（0~15）
      "n₁ bits → n₂ bits，多少倍"2ⁿ²⁻ⁿ¹ 倍32→128 bit → 2⁹⁶ 倍
      "末尾追加 k 个 0"×2ᵏ追加 3 个 0 → ×8

      重难点 2：溢出 vs 舍入的判别（近三年每套卷都考）

      问自己两个问题：

      1. 出问题的数是整数运算还是实数（小数/除法）运算？整数 → 溢出方向想；实数 → 舍入方向想。

      2. 症状是"数太大装不下"（含变负数）还是"精度不够/不精确"？前者 overflow，后者 round-off。

      重难点 3：模拟数据的数字化（采样）

      识别标准答案的特征词："sampled at regular intervals" + "each sample represented as a sequence of bits"。凡是选项里出现这两个要素的基本就是正确答案。干扰项常用"预测（predict）""估计（estimation）""存成文本"等说法。

      易错点

      • 追加 0 是 ×2，不是 ×10：二进制 11101 追加 3 个 0 变成 8 倍，不是 1000 倍。
      • "表示不了操作数" vs "表示不了和"：4 bits 表示 14、15 都没问题（≤15），但和 29 超了——溢出原因是和超范围，不是操作数超范围。读选项要抠这句。
      • 溢出不只"变成更大的错数"：也可能显示为负数（有符号存储时进位侵入符号位）。
      • round-off 的锅是"固定 bit 存实数"：不是"溢出"，也不是"语言不支持实数"。
      • min bits 别忘了验证下界：2ⁿ ≥ N 用"≥"不是">"——恰好等于时也够（如 128 个值用 7 bits）。
      • 十六进制换算：1 位 hex = 4 bits。56₁₆ = 5×16 + 6 = 86₁₀，再查 ASCII 表。

      Topic 2.2 Data Compression（数据压缩）

      知识点梳理（DAT-1.D）

      Lossless 无损Lossy 有损
      还原可完全还原原始数据只能还原出近似版本，不可还原
      压缩率通常较小通常显著更大（压得更小）
      适用场景质量/可还原性最重要：文档存档、程序、需精确恢复的数据尺寸/传输时间最重要：流媒体、照片、音乐库
      例子ZIP、byte pair encodingJPEG、MP3、流媒体视频

      核心概念句（DAT-1.D 原文级考点）：

      • 压缩可以减少存储/传输的 bit 数；bit 更少 ≠ 信息更少（Fewer bits does not necessarily mean less information）。
      • 压缩量取决于原始数据的冗余度（redundancy）和所用算法。
      • 选择标准：质量或可还原性最重要 → lossless；最小化体积或传输时间最重要 → lossy。

      Byte Pair Encoding（字节对编码，常考的 lossless 实例）：把字符串中出现超过一次的字符对替换为一个未出现过的字符，并保存映射表；因为映射表可逆，属于无损。

      图像变换的无损/有损判别（高频）：

      • 创建负片（每个像素 new = 255 − old）：可逆 → 无损。
      • 创建灰度（对 R、G、B 取平均，三分量并成一个）：丢信息 → 有损。
      • "可能有轻微画质损失地压缩"：有损。

      重难点

      重难点 1：场景选择题——该用哪种压缩？

      抓题干关键词：

      • "restore to original / archival / full quality / 完全恢复" → lossless
      • "maximize the number of songs / minimize size / transmission time / 流媒体" → lossy
      • 反套路：最大容量存音乐 → lossy（牺牲音质换数量）；画廊大格式打印照片 → lossless（质量优先）。

      重难点 2：Byte Pair Encoding 两类问法

      1. "为什么是 lossless？"——因为有映射表可以完整还原（不是因为"安全"，也不是因为"丢弃了数据"）。

      2. "哪个字符串不能被缩短？"——找没有任何字符对出现超过一次的串。逐对检查："LEVEL_UP" 的所有相邻对（LE、EV、VE、EL、L_、_U、UP）各出现一次 → 无法缩短。

      重难点 3：压缩 ≠ 加密

      压缩与安全的三个经典错误选项：压缩"保证信息安全不被截获"（✗）、"保证不被未授权用户解读"（✗）、"可以防止拦截"（✗）。压缩只管大小，保密要靠加密。

      易错点

      • lossless 的优势只有一个：能完全还原。它不比 lossy 压得小、不一定传输更快、不更安全。
      • 有损压缩反复压缩→质量持续下降；"反复压缩解压质量不变"是错误说法。
      • " Fewer bits ≠ less information"：压得小不代表丢信息（lossless 压缩就是反例）。
      • 删除 metadata 不影响主数据：反过来，主数据变了 metadata 也未必跟着变。
      • 视频网站把计数器从 32-bit 换 64-bit 属于表示范围问题（2³² 倍），跟压缩无关——别被压缩章节的背景迷惑。

      Topic 2.3 Extracting Information from Data（从数据中提取信息）

      知识点梳理（DAT-2.A / 2.B / 2.C）

      （1）信息与数据（DAT-2.A）

      • Information = 从数据中提取出的事实与模式（facts and patterns）。
      • 数据能帮助发现趋势、建立联系、解决问题；常常单一数据源不够，需要合并多个来源才能下结论。
      • 相关 ≠ 因果（correlation does not imply causation）：数据里发现两个变量相关，不代表存在因果关系，需要进一步研究。

      （2）Metadata 元数据（DAT-2.B，本章最高频考点）

      • Metadata = data about data（关于数据的数据）。照片是 data；拍摄日期、时间、GPS 位置、文件大小、作者、尺寸、版权是 metadata。
      • 对 metadata 的修改/删除不改变主数据。
      • Metadata 的用途：查找（finding）、组织（organizing）、管理（managing）信息；让数据更易用、可结构化。

      （3）处理数据的挑战（DAT-2.C）

      • 数据集无论大小都有挑战：需要清洗（cleaning）、不完整（incomplete）、无效（invalid）、需要合并多源。
      • 数据不均匀：开放文本框收集的数据，缩写、拼写、大小写五花八门（生日可以是 02/01/2003 或 Feb 1, 2003）。Cleaning = 把数据变统一但不改变含义（如把所有等价缩写/拼写统一成同一个词）。
      • Bias 偏见：由数据类型或来源造成；收集更多数据并不能消除偏见。
      • 规模问题：超大数据集单机难处理，可能需要并行系统；系统的可扩展性（scalability）决定能怎么处理数据。

      重难点

      重难点 1：data vs metadata 一票判断法（每年 2–3 题）

      问：这个信息是"内容本身"还是"关于内容的描述/属性"？

      • 照片的像素颜色、音频的声波、消息正文、视频画面 → data
      • 拍摄时间/地点、文件大小、上传者、点赞数、通话双方号码、文件创建时间 → metadata
      • 题目问"分析 metadata 更合适"的场景：与时间、地点、人、次数、管理有关的问题（何时拍的、在哪拍的、谁传的、被评论几条）。
      • 题目问"分析 data 更合适"的场景：与内容有关的问题（照片里是不是天空、消息在聊什么话题、照片里有几个人）。

      重难点 2："只给这些数据，能/不能回答什么？"

      解题步骤：把题干列出的字段清单圈出来，逐项对照选项——

      • 选项需要的信息字段里有 → 能回答（哪怕要计算/排序/计数）。
      • 字段里没有（比如没有"单价"、没有"个人信息"、没有"天气"、没有"其他人的数据"）→ 不能回答。
      • 经典陷阱：数据库按"城市+次数"汇总，就推不出个人购买记录；记录了"借出/归还日期"就推不出"从未被借过的书"。

      重难点 3：bias 与数据收集方式

      • 自愿参与的调查（voluntary response）、来自单一渠道的数据 → 有偏见。
      • 菜单式（1~5 选择题）收集的数据格式统一，基本不需要清洗；开放文本框收集的数据需要大量清洗。
      • "多收集数据就能消除偏见"——永远错误。

      易错点

      • 副本不是 metadata："A duplicate copy of the data" 是数据本身，LEAST likely to be metadata 的标准答案。
      • 照片尺寸（行列数）是 metadata——虽然它看起来很"内容"，但它是关于图像文件的描述信息。
      • 改 metadata ≠ 改 data：删掉照片的 GPS 信息，照片像素不变。
      • correlation ≠ causation：选项里出现"X 导致 Y"而数据只显示相关性时，警惕。
      • 能"计算出来"也算"能回答"：不能回答指的是信息缺失，不是需要计算。
      • 趋势外推：数据"以大致恒定速率增长"，可线性外推两年后的值（用最后两年的增量外推）。

      Topic 2.4 Using Programs with Data（用程序处理数据）

      知识点梳理（DAT-2.D / 2.E）

      （1）用程序提取信息（DAT-2.D）

      • 程序处理数据以获取信息；表格、图表、文本等可视化工具用来传达洞见。
      • 常用工具：search（高效查找）、filter（筛选+发现模式）、spreadsheet（组织信息、找趋势）。
      • 四类标准处理动作（DAT-2.D.6，写作题也用得上）：

      1. Transform 变换每个元素（如列表每个数 ×2）

      2. Filter 筛选（只留正数、只留选了乐队的學生）

      3. Combine/Compare 合并或比较（求和、找最高 GPA）

      4. Visualize 可视化（图表）

      （2）用程序获得洞见（DAT-2.E）

      • 程序以迭代、交互的方式处理数据，逐步获得洞见。
      • 程序员用程序 filter 和 clean 数据；combining（合并）、clustering（聚类）、classifying（分类） 数据是获取知识的过程。
      • 对数据进行转换（transform）后，模式（patterns）会浮现。

      重难点

      重难点 1：filter + sort 的执行顺序（每年必考的"步骤排序"题）

      关键假设（题干会给）："applying either of the filters will not change the relative order of the remaining rows"（筛选不改变剩余行的相对顺序）。

      由此推出结论：

      • filter 与 filter 之间：顺序任意（互不影响结果）。
      • filter 与 sort 之间：因为 filter 保序，"先 sort 后 filter" 与 "先 filter 后 sort" 最终顺序相同 → 都可以。
      • 但无效动作会让序列错误：sort by 无关列（如 sort by subject）放在最后 → 第一行不是答案；漏掉必要的 filter（如没滤掉 year = −1 的行）→ 第一行可能是脏数据。
      • 检验口诀："最后一行动作做完时，第一行必须恰好是答案"——逐项模拟即可。

      重难点 2：布尔筛选表达式（AND/OR 嵌套）

      • 同时满足多个条件 → 条件间用 AND；满足其一即可 → 用 OR。
      • 复合条件："价格 ≤ $30"即 "lo" OR "med"；再与"评分 ≥ 4.0"用 AND 连接：

      (avgRating ≥ 4.0) AND ((prcRange = "lo") OR (prcRange = "med"))

      • 经典陷阱：((day = "Saturday") AND (day = "Sunday")) 永远为 false——一个字符串不可能同时等于两个值。"周六或周日"必须用 OR。
      • 注意边界：num ≥ 1 写成 1 ≤ num；"at least one copy" 是 ≥1 不是 >1。

      重难点 3：多数据文件联查（外键串联）

      标准链式推理（如"给买了 AA 电池产品的客户发邮件"）：

      Products（找用 AA 的 Product ID）→ Purchases（用 Product ID 找 Customer ID）→ Customers（用 Customer ID 找 e-mail）

      口诀："要什么，就从存这个信息的文件往回倒推"。两个文件必须能通过公共字段（ID）连接。

      易错点

      • "shorten 再 keep palindromes"不行：shorten 之后信息丢失，无法再判断回文——破坏信息的步骤不能放在需要该信息的步骤之前。
      • RemoveDuplicates 的作用域：分别对两个列表去重，不能去除"两个列表都有的重复项"；必须 Combine 之后再统一去重。
      • ignore 条件必须先 filter：year = −1、rating = −1、photographer = "(unknown)" 都是"未知值"哨兵，算法必须先把它们滤掉。
      • AND/OR 写反：句子里的"或"用 OR、"且"用 AND；嵌套时给 OR 加括号。
      • "数据文件太大程序处理不了"几乎总是错误选项——现代系统的瓶颈是数据格式不统一，不是行数太多。

      Q5（考点：DAT-1.B.1 溢出判断，反套路）

      A certain programming language uses 8-bit binary numbers to represent nonnegative integers. Using this programming language, a programmer attempts to add the decimal values 90 and 150. Which of the following best describes the result of this operation?

      • AAn overflow error will occur because 8 bits is not large enough to represent either 90 or 150.
      • BAn overflow error will occur because 8 bits is large enough to represent 90 but not 150.
      • CAn overflow error will occur because 8 bits is large enough to represent 90 and 150 but not the sum 240.
      • DNo overflow error will occur; the sum 240 can be represented using the 8-bit representation.

      正确答案：D

      解析：8-bit 无符号范围 0~255。90 ✓、150 ✓、和 240 ≤ 255 ✓——全程不超范围，不溢出。本题是官方设置的反套路：多数溢出题答案都是"溢出"，这题偏偏不是。必须老老实实算 2⁸−1=255 再比较，不能凭题型惯性选 C。

      Q29（考点：DAT-1.B.3 浮点近似/舍入误差）

      A program displays the result of the operation 5.0 / 3.0 as the value 1.6666666666666667. Which of the following is the most likely explanation for this result?

      • AThe operation uses lossy compression to represent the result of 5.0 / 3.0.
      • BThe operation produces a syntax error because when using real numbers, 5.0 is not divisible by 3.0.
      • CThe result produces an overflow error because the programming language uses a fixed number of bits to represent real numbers.
      • DThe result is represented as an approximation because the programming language uses a fixed number of bits to represent real numbers.
      点击选项作答，选后显示正确答案与解析

      正确答案：D

      解析：5.0/3.0 = 1.666… 是无限循环小数，固定 bit 的浮点存储只能近似表示 → 末尾出现 …67 的舍入痕迹。这是 round-off（近似），不是溢出（C 错：实数题不谈 overflow）、更不是压缩（A 错）或语法错误（B 错）。

      Two lists contain names of books. A librarian wants to create newList containing all books found in either list, in alphabetical order, with duplicate entries removed. Available procedures: Combine(list1, list2)、Sort(list)、RemoveDuplicates(list). Which code segment correctly creates newList?

      • AnewList ← Combine(list1, list2); newList ← Sort(newList); newList ← RemoveDuplicates(newList)
      • Blist1 ← Sort(list1); list2 ← Sort(list2); newList ← Combine(list1, list2); newList ← RemoveDuplicates(newList)
      • Clist1 ← RemoveDuplicates(list1); list2 ← RemoveDuplicates(list2); newList ← Combine(list1, list2); newList ← Sort(newList)
      • Dlist1 ← RemoveDuplicates(list1); list1 ← Sort(list1); list2 ← RemoveDuplicates(list2); list2 ← Sort(list2); newList ← Combine(list1, list2)
      点击选项作答，选后显示正确答案与解析

      正确答案：A

      解析：关键陷阱：跨列表的重复（两个列表都有 "Frankenstein"）。C 先各自去重，合并后仍会有跨列表重复 → ✗。A 先合并（重复还在）→ 排序 → 统一去重 → ✓。D 连排序都没做完（合并后未排序）→ ✗。

      APC 2.4-Q6（考点：DAT-2.E 多数据文件联查）

      A company uses data files: Customers（Customer ID, address, e-mail, phone）、Products（Product ID, name, type of battery used）、Purchases（Product ID, product serial number, Customer ID）. A new rechargeable battery pack is available for products that use AA batteries. Which of the following best explains how the data files can be used to send a targeted e-mail to only those customers who have purchased products that use AA batteries?

      • AUse the customer IDs in the purchases file to search the customers file to generate a list of e-mail addresses
      • BUse the product IDs in the purchases file to search the products file to generate a list of product names that use AA batteries
      • CUse the customers file to generate a list of customer IDs, then use the list of customer IDs to search the products file to generate a list of product names that use AA batteries
      • DUse the products file to generate a list of product IDs that use AA batteries, then use the list of product IDs to search the purchases file to generate a list of customer IDs, then use the list of customer IDs to search the customers file to generate a list of e-mail addresses
      点击选项作答，选后显示正确答案与解析

      正确答案：D

      解析：链条：Products（谁用 AA 电池 → Product ID）→ Purchases（这些 Product ID 被谁买过 → Customer ID）→ Customers（这些 ID 的 e-mail）。"要 email，倒着找"——A、B、C 都只走了链条的一段。

      APC 2.4-Q7（考点：DAT-2.D 布尔筛选表达式（OR 嵌套））

      A student wants to count the number of restaurants whose price range is $30 or less and whose average customer rating is at least 4.0. In the spreadsheet, prcRange contains the price range as a string ("lo" = under $10, "med" = $11 to $30, "hi" = over $30), and avgRating contains the average customer rating. Which expression evaluates to true exactly when the restaurant should be counted?

      • A(avgRating ≥ 4.0) AND ((prcRange = "lo") AND (prcRange = "med"))
      • B(avgRating ≥ 4.0) AND ((prcRange = "lo") OR (prcRange = "med"))
      • C(avgRating ≥ 4.0) OR ((prcRange = "lo") AND (prcRange = "med"))
      • D(avgRating ≥ 4.0) OR ((prcRange = "lo") OR (prcRange = "med"))
      点击选项作答，选后显示正确答案与解析

      正确答案：B

      解析："≤ $30" = lo 或 med → 内层 OR；与评分条件同时满足 → 外层 AND。A 的内层 AND 恒假（一个字符串不能同时等于两个值）。

      APC 2.4-Q8（考点：DAT-2.D filter/sort 全序（I/II/III 判定））

      A student is developing an algorithm to determine which of the restaurants that accept credit cards has the greatest average customer rating. Restaurants with no ratings and restaurants that do not accept credit cards are to be ignored. Available actions: Filter by number of ratings、Filter by payment type、Sort by rating（按列 D 从大到小）. Assume that applying either of the filters will not change the relative order of the rows remaining in the spreadsheet. The desired restaurant will appear in the first row. Which of the following sequences of steps can be used?

      1. Filter by number of ratings, then filter by payment type, then sort by rating

      2. Filter by number of ratings, then sort by rating, then filter by payment type

      3. Sort by rating, then filter by number of ratings, then filter by payment type

      • AI and II only
      • BI and III only
      • CII and III only
      • DI, II, and III
      点击选项作答，选后显示正确答案与解析

      正确答案：D

      解析：filter 保序 → filter 放在 sort 前后都行，最终都是"滤净后按评分降序" → 三种序列全部可行 → D。与 2025 卷 Q15（II 可行）同理。注意：最后一个动作必须让"第一行 = 答案"。

      APC 2.4-Q9（考点：DAT-2.D filter/sort + 哨兵值（双选））

      A large spreadsheet contains information about the photographs in a museum's collection: photographer, subject, year, publicly available. Unknown photographers are set to "(unknown)" and unknown years are set to −1. A student wants to determine the name of the photographer who took the oldest photograph; photographs whose photographer or year are unknown are to be ignored. The desired entry will appear in the first row. Available actions: Filter by photographer、Filter by year、Sort by subject、Sort by year（从最小到大）. Assume filters do not change the relative order of remaining rows. Which of the following sequences of steps can be used? Select two answers.

      • AFilter by photographer, then filter by year, then sort by subject
      • BFilter by photographer, then filter by year, then sort by year
      • CSort by subject, then sort by year, then filter by photographer
      • DSort by year, then filter by year, then filter by photographer
      多选题，共 2 项 — 点击任一选项查看答案

      正确答案：B、D

      解析：A ✗：最后按 subject 排序，第一行不是"最老照片"。C ✗：漏了 Filter by year——year=−1 的行会排在最前面（−1 比所有年份都小），第一行可能是未知年份的照片。B ✓：滤净后按年份升序。D ✓：先按年排，再滤掉 −1 和 unknown——filter 保序，排序结果保留。

      APC 2.4-Q10（考点：DAT-2.D 布尔筛选表达式（OR））

      A student wants to count the number of shows that meet both of the following criteria: is a talk show, and is on Saturday or Sunday. For a given row, genre contains the genre as a string and day contains the day as a string. Which expression evaluates to true exactly when the show should be counted?

      • A(genre = "talk") AND ((day = "Saturday") AND (day = "Sunday"))
      • B(genre = "talk") AND ((day = "Saturday") OR (day = "Sunday"))
      • C(genre = "talk") OR ((day = "Saturday") AND (day = "Sunday"))
      • D(genre = "talk") OR ((day = "Saturday") OR (day = "Sunday"))
      点击选项作答，选后显示正确答案与解析

      正确答案：B

      解析：两个条件同时满足 → genre 与日期用 AND；"周六或周日" → 内层 OR。A 的内层 AND 恒假。这是 AND/OR 最标准的"母题"，2.4-Q2/Q7 都是它的变体。

      Create Performance Task 的 Written Response 2 直接考"数据抽象"：

      Written Response 2（Data Abstraction / Procedural Abstraction）

      关于数据抽象（data abstraction），评卷标准要求你能：

      1. 指出程序中哪里用了 list 来管理数据复杂度（如何用 list 把多个相关的数据项组织在一起）；

      2. 解释数据抽象如何帮助管理复杂度：list 让程序可以用同一个名字引用整组数据、方便遍历/增删元素；当数据条数变化时程序无需改动（data abstraction 让程序更灵活）；

      3. 说明如果没有 list 会怎样：需要为每个数据项单独建变量，重复代码暴增、难以维护。

      写作模板（背下来）：

      "In my program, I used a list called scores to store all the user's scores. Data abstraction helped manage complexity because I could process all scores with one loop instead of creating a separate variable for each score. If the number of scores changes, the program still works without modification."

      与 Big Idea 2 知识点的对应

      • 数据要能被程序处理（DAT-2.D）→ 你的程序里至少要有"从列表/文件中筛选、汇总、变换数据"的片段，写 WR2 时直接引用。
      • 在解释程序目的时（WR1），如果能提到"程序用数据发现信息/生成新知识"（DAT-2），能同时呼应 Big Idea 2 的评分视角。
      • 注意：Create PT 不考二进制计算与压缩，那两部分只在 MCQ 出现。

      备考策略与应试技巧

      1. 2 的幂表默写：2⁰~2¹⁰ + 2¹⁶ + 2³² 必须条件反射。min bits、倍增、范围三题型全靠它。

      2. 溢出 vs 舍入三秒判别：整数+大数 → overflow；小数/除法不精确 → round-off。看关键词 "fixed number of bits"。

      3. data vs metadata 条件反射：时间/地点/人/大小/次数 → metadata；内容本身 → data。"副本"永远不是 metadata。

      4. filter/sort 题的固定套路：记住"filter 保序"这个题干假设 → filter 与 sort 可交换；用"最后一步做完第一行是不是答案"逐项模拟；检查有没有漏滤哨兵值（−1 / "(unknown)"）。

      5. AND/OR 检查法：把每个选项代入一个反例。(day="Sat") AND (day="Sun") 代入任何值都假 → 秒杀。

      6. 多文件联查画箭头：在草稿纸上把文件画成框，用 ID 画箭头，从"要的答案"倒推。

      7. 易错清单（考前最后看）：追加 0 = ×2ᵏ 不是 ×10ᵏ；位数差是指数；"多 2 个"vs"2 倍"；压缩≠加密；汇总数据推不出个体；多收集数据不消除偏见；menu 输入格式统一。

      8. 刷题优先级：AP Classroom 2.1/2.3/2.4 三套全刷（2.2 题少可全刷），错题按 §5 速查表编号归类。本手册 §6 全部题目建议做两遍：第一遍做题，第二遍只看解析验证思路。
