          APCSP 备考手册 · Big Idea 5 计算的影响（Impact of Computing）

          本章定位

          考试权重：21–26%——五个 Big Idea 中的第二权重（仅次于 Big 3 的 30–35%），而且几乎不考代码，是"背多分"章。

          Big Idea 5 含 6 个 Topic，围绕一条主线：计算创新会带来意料之外的影响，如何在享受好处的同时规避法律、伦理与安全风险。

          Topic 5.1 Beneficial and Harmful Effects（有益与有害影响）

          知识点梳理（IOC-1.A / IOC-1.B 逐条）

          • IOC-1.A.1~5：计算创新由人创造；人们完成任务的方式会随之改变；并非所有影响都能事先预见；同一个影响可以被不同的人（甚至同一个人）同时视为有益和有害；计算进步带动了医学、工程、通信、艺术等领域的创造力。
          • IOC-1.B.1：计算创新常被用于创作者未曾设想的用途。官方给的经典三例必须记住：
          • WWW 最初只为科学界快速方便地交换信息而设计；
          • 定向广告（targeted advertising） 帮助企业，但在个人和群体层面都可能被滥用；
          • 机器学习与数据挖掘 推动了医学/商业/科学创新，但发现的信息也曾被用来歧视群体。
          • IOC-1.B.2：某些用法会对社会、经济或文化产生有害影响。
          • IOC-1.B.3 / 1.B.4（一对高频对偶）：负责任的程序员会尽力考虑创新的意外用途及其利弊；但不可能考虑所有用法——"程序员能预见一切"是必错说法。
          • IOC-1.B.5：创新常带来意外的有益影响（催生其他领域的进步）。
          • IOC-1.B.6：程序被快速传播或拥有大量用户时，会产生超出程序员意图或控制的重大影响。

          重难点

          • "一个影响，两种评价"是 5.1 的灵魂：GPS 方便导航（益）也暴露行踪（害）；云端协作提高效率（益）也引入数据安全顾虑（害）。答案永远选"两面性"最贴切的选项。
          • 评价对象是计算创新（computing innovation）而非"计算机"——app、GPS、机器学习模型都算。

          易错点

          • "开发者存储用户数据"的 benefit 几乎总选"分析数据以改进应用"（IOC-1.B.1 定向广告的正反面）——"确保数据中没有模式""减少加密需求"都是干扰项。
          • 云计算（cloud computing）三句官方定性：增强协作 ✓、引入新的数据安全顾虑 ✓、消除路由冗余的需求 ✗、减少知识产权顾虑 ✗（后两个必错）。

          Topic 5.2 Digital Divide（数字鸿沟）

          知识点梳理（IOC-1.C 逐条）

          • IOC-1.C.1 / 1.C.2：互联网接入因社会经济地位（socioeconomic）、地理（geographic）、人口特征（demographic）以及国家而异；digital divide 指的就是这种获取计算设备与互联网的差异。
          • IOC-1.C.3：数字鸿沟既影响群体也影响个人。
          • IOC-1.C.4：它引发公平（equity）、接入（access）、影响力（influence）问题——全球与本地层面皆是。
          • IOC-1.C.5：数字鸿沟受个人、组织、政府行动的影响（可以扩大也可以缩小）。

          重难点：缓解 vs 扩大措施判别法

          问"哪个动作最可能缩小数字鸿沟"时，正确项的共同特征：降低获取设备/网络/技能的门槛（免费或低价设备、偏远地区基础设施、社区免费上网点、面向不同身体条件的无障碍设计）。问"哪个扩大鸿沟/最无效"时，选把服务整体搬到线上、要求用户自带设备、只服务高级用户的那一项——它要求用户先有设备才能受益。

          易错点

          • "把所有政府表格放到城市网站上"看似便民，实际最无效——没有设备/网络的人反而更难办事（APC 5.2-Q3 官方答案 C 的逻辑）。
          • "家长限制孩子上网时间"不是数字鸿沟的成因（那是使用偏好，不是接入差异）。
          • 官方 liking 的缩小手段：政府修建网络基础设施 ✓、无障碍设计 ✓、免费培训 ✓、低价设备 ✓；限制网络访问 ✗、只面向高级用户设计 ✗。

          Topic 5.3 Computing Bias（计算偏差）

          知识点梳理（IOC-1.D 逐条）

          • IOC-1.D.1：计算创新可能反映既有的人类偏差——因为算法里写进了偏差，或训练/输入数据本身有偏差。
          • IOC-1.D.2：程序员应主动采取行动减少算法偏差，以对抗既有的人类偏差。
          • IOC-1.D.3：偏差可能嵌入软件开发的所有环节（数据收集、算法设计、测试、用户反馈）。

          重难点：去偏差的万能答案

          问"哪个策略最不可能引入偏差 / 最能减少偏差"时，找"从全体用户中随机抽样（random sample of all users）"——随机化是官方唯一反复背书的去偏差手段。反之，"只测开发者身边/公司员工/最活跃用户/青少年用户"都是引入偏差的典型做法（样本不具代表性）。

          易错点

          • 偏差不只来自"数据"，算法本身和分析结果的人也可能带入偏差（2025 Q21：documentation 是唯一与数据处理无关的环节，故"最不可能引入偏差"）。
          • GPS 类游戏的偏差：城市兴趣点（POI）密度高 → 有利于城市玩家，这是"数据代表性偏差"的标准案例。

          Topic 5.4 Crowdsourcing（众包）

          知识点梳理（IOC-1.E 逐条）

          • IOC-1.E.1：广泛获取信息与公共数据，有助于发现问题、开发方案、传播结果。
          • IOC-1.E.2 / 1.E.3：科学已被分布式与"公民科学"改变；citizen science = 由分布式个人（许多并非科学家）用自己的计算设备为研究贡献数据的科研方式。
          • IOC-1.E.4（定义题考点）：crowdsourcing = 通过互联网从大量人群获取输入或信息。
          • IOC-1.E.5 / 1.E.6：协作能增强人的能力；众包催生新模式（如为商业或社会事业对接众筹资金）。

          重难点：crowdsourcing 判别两要素

          同时满足才算众包：① 从大量人那里 ② 获取输入/信息。只有"把成果提供给大众用"而不收集大众输入的，不是众包（2025 Q45 答案 B：教授把文本分析软件挂上网供人使用——单向提供，无输入）。公民科学是众包在科研场景的特例：志愿者贡献数据（观鸟录音、海滩垃圾照片、蝴蝶计数）。

          易错点

          • "分布式群体比单个研究者更准确" ✗——公民科学的优势是更快/覆盖更广，不是更准（APC 5.4-Q3 答案 D 的措辞是"研究团队自己分析要花更长时间"）。
          • "众包能解决所有计算问题" ✗（III 选项错误：undecidable 问题与算力无关，与 Big 3 Topic 3.18 联动）。
          • 交通 app"用户实时上报路况"是典型众包；"保存地址""接收事故提醒"不是。

          Topic 5.5 Legal and Ethical Concerns（法律与伦理问题）

          知识点梳理（IOC-1.F 逐条）

          • IOC-1.F.1~3：计算机上创作的材料是创作者（或组织）的知识产权（intellectual property）；数字化信息的易获取、易分发特性引发了关于所有权、价值、使用的知识产权担忧；应采取措施保护知识产权。
          • IOC-1.F.4：未经许可使用他人材料并当作自己的 = plagiarism（剽窃），可能有法律后果。
          • IOC-1.F.5（三大合法使用方式，必背）：
          • Creative Commons：公共版权许可，让创作者可以免费授权他人分享、使用、再创作自己的作品；no-rights-reserved（CC0）= 完全不保留权利；
          • open source：程序免费提供、可再分发和修改；
          • open access：在线研究成果无访问限制、无多数使用限制。
          • IOC-1.F.6：使用他人创作的材料永远要注明出处（cite）。
          • IOC-1.F.7：CC / open source / open access 让数字信息获得更广泛的使用。

          重难点：CC 许可证 vs 传统版权

          传统版权默认"保留所有权利"；Creative Commons 让创作者自己指定别人可以怎样免费使用/分享/再创作。判别题套路："符合 CC 许可条款地使用"= 合法；"使用无许可的版权材料"= 违法/伦理问题。例如：按 CC 许可采样音乐 ✓；文章里放版权图片发表 ✗；从同学共享文件夹下载教材（版权材料）✗。

          易错点

          • open source 的 "NOT an advantage" 官方答案："原作者提供免费/低价安装支持"——开源不承诺商业支持（APC 5.5-Q2 答案 C）。
          • "以 CC 许可发布自己作品"的直接好处 = 能指定他人合法使用与分发的方式（不是"防剽窃"，更不是"加密"）。
          • 把单用户许可软件装到机房所有电脑上 = 不道德使用；共用前须获版权所有者许可。

          Topic 5.6 Safe Computing（安全计算）

          知识点梳理（IOC-2.A / 2.B / 2.C 逐条）

          IOC-2.A 隐私风险（PII）：

          • PII（personally identifiable information）= 能识别特定个人的信息：姓名、SSN、邮箱、生日、住址、信用卡号等；PII 存在网上可简化购物，但也带来风险。
          • 信息一旦上网很难删除；程序可收集你的位置（去过哪、怎么去的、待了多久）；社交媒体信息与他人信息聚合（aggregate）后可推断出私密信息；PII 可被用于跟踪（stalk）、盗用身份（identity theft）或策划其他犯罪。
          • 商业与政府的信息整理若忽视隐私保护，可能被利用（exploited）。

          IOC-2.B 保护措施：

          • 认证（authentication）保护设备与信息免遭未授权访问；强密码 = 用户好记、他人难猜。
          • 多因素认证（multifactor authentication）：成功出示至少两类证据才能访问——knowledge（知道的：密码）、possession（持有的：手机验证码、USB 令牌）、inherence（本身的：指纹）。每多一步 = 多一层防护。只输错密码锁定账号不是 MFA（那是同一类证据的惩罚机制）。
          • 加密：编码数据防止未授权访问。对称加密 = 加解密用同一个密钥（双方都要保密持有）；公钥加密 = 公钥加密 + 私钥解密，发件人不需要收件人私钥即可加密，但只有收件人私钥能解密。（数学细节不考——官方 Exclusion Statement。）
          • 证书颁发机构（certificate authority）：签发数字证书，验证加密密钥的归属真实性（信任模型）。
          • 病毒/恶意软件：virus 能自我复制、未授权进入系统，常附着在合法程序上；malware 旨在破坏系统或部分控制其运行；扫描软件 + 定期更新（修复可被利用的设计缺陷）可防护；用户应检查程序的权限设置。

          IOC-2.C 未授权访问手段：

          • phishing：诱骗用户提供个人信息（假邮件/假网站），进而访问银行、邮箱等敏感资源。
          • keylogging：记录每一次按键，用于窃取密码等机密信息。
          • rogue access point：给未授权者接入安全网络的无线接入点；公共网络上的数据可被拦截、分析、篡改。
          • 恶意链接可伪装在网页或邮件里；未经请求的邮件、附件、链接、表单都可能危害系统——熟识的发件人若账号被盗同样危险。

          重难点：加密题的"钥匙配对"口诀

          • 对称：一把钥匙，双方共用（Finn/Gwen 字母映射题：同一张密表先映射再逆映射）。
          • 公钥：公钥上锁，私钥开锁；收件人用自己的私钥解密；"拿到公钥就能解密"必错（公钥只能加密）。
          • 想私密传输 → 最安全的是公钥加密；"高带宽""冗余路由""CC 许可"都与保密无关。

          易错点

          • 匿名窗口（anonymous window）只删除本机浏览记录和 cookie——网络管理员仍能看到你的流量、病毒照样感染、购物车在服务器端的记录不受影响（APC 5.6-Q1 答案 B："购物车不会被保存在你电脑上"是对的）。
          • 隐私风险题找"聚合/推断"与"未授权访问"两类：4 位 PIN 只有 10,000 种组合 → 穷举可行（2025 Q61）；公共电脑自动填充密码 → 下一位用户可能进入你的账号（2025 Q62）。
          • 邮件危害双选题的正解组合永远是 恶意链接 → 装恶意软件 + 附件 → 键盘记录器；"邮件里有公钥""有损压缩过的邮件"都不是风险。

          考前速查表

          1. 创新的影响可益可害；同一影响可同时被看作益与害；程序员无法预见所有用途。

          2. WWW 诞生于科学界信息交换需求；定向广告与机器学习是"双刃剑"标准案例。

          3. 数字鸿沟 = 设备/网络获取差异（社会经济、地理、人口特征）；缩小靠降门槛（设备、基建、培训、无障碍）。

          4. 偏差来自算法、数据、分析者；去偏差万能词 = random sample of all users。

          5. crowdsourcing = 互联网 + 从大量人获取输入；公民科学 = 众包贡献科研数据。

          6. 知识产权：未经许可使用 = 侵权；当作自己的 = plagiarism；引用他人材料永远要 cite。

          7. Creative Commons 指定他人如何合法使用；open source 可改可发；open access 无访问限制。

          8. PII 上网难删除；聚合可推断私密；位置数据可被滥用。

          9. MFA = 至少两类证据（知道/持有/本身）；错三次锁号不是 MFA。

          10. 对称加密 = 一把共用密钥；公钥加密 = 公钥加密、私钥解密；发件人无需收件人私钥。

          11. certificate authority 验证密钥归属，不是查病毒、不是 DNS。

          12. phishing 诱骗给信息；keylogging 记录按键；rogue access point 假接入点窃听。

          13. 匿名窗口 ≠ 匿名上网：管理员可见、病毒可感染。

          14. "encrypted with public key → decrypt with recipient's private key" 是年年考的送分链。

          15. 情景题先分类：问 benefit 找"正面直接效果"，问 privacy risk 找"未授权者能拿到什么"，问 legal concern 找"版权/许可"。

          1. 术语三件套优先：本章 60% 的分数来自 5.6 的术语精确记忆——phishing / keylogging / malware / virus / rogue access point / MFA / symmetric vs public key / certificate authority，每个用"一句定义 + 一个反例"记（§6.1 的每个术语都配好了）。
