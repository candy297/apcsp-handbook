                      Create Performance Task（创造性性能任务 · 30%）

                      本章定位：Create PT 占多少分

                      Create Performance Task（下称 CPT）是 AP CSP 唯一的非选择题计分部分，占总分 30%。它由两部分组成：课前在课堂完成并提交的程序作品（代码 + 视频 + 个性化项目参考），以及考试当天在 Bluebook 里作答的 4 道书面回答题（Written Responses，60 分钟）。考试当天答题时，监考系统会把你自己提交的 Personalized Project Reference 发回给你参照作答——这就是 CPT 的"开卷资料"。

                      官方考试结构（CED 2023, p163）：

                      Section内容题量权重时长
                      I选择题（57 单选 + 5 创新阅读 + 8 多选）7070%120 分钟
                      IICPT 作品提交（代码/视频/PPR，课堂 ≥9 小时完成）—30%（与下行合计）课内 ≥9 小时
                      II考试日书面回答（Written Response × 4）430%（与上行合计）60 分钟

                      六个评分行（Rubric Rows，1 行 1 分，共 6 分）——Row 1/2 评提交的视频与程序，Row 3–6 评考试日的四道书面回答（CED 2023 p169；2024 与 2026 官方成绩报告同构）：

                      Row名称评定载体考查能力（Skill）
                      Row 1Video提交的视频（演示输入/功能/输出）2.B 实现并应用算法
                      Row 2Program Requirements提交的代码（六要素齐全）2.B 实现并应用算法
                      Row 3Program Design, Function, and Purpose考试日 WR1（=3a）1.A 调查情境/任务
                      Row 4Algorithm Development考试日 WR2(a)（=3c.iv）4.A 解释代码如何运行
                      Row 5Errors and Testing考试日 WR2(b)（=3d）4.C 测试与纠错
                      Row 6Data and Procedural Abstraction考试日 WR2(c)（=3b 全部 + 3c.i–iii）3.C 解释抽象

                      关键规则（官方原文）：On the AP Exam, to earn a point for a rubric row, responses will need to meet all criteria for that row. 每一行必须同时满足该行全部判据才得 1 分——部分满足 = 0 分，没有半分。

                      与各章的联动：Q1 ↔ Big Idea 1（CRD-2.A–G）；Q2(a) ↔ Big Idea 3 算法三结构；Q2(b) ↔ 测试策略（Big Idea 1 开发过程）；Q2(c) ↔ Big Idea 3 的 list 与过程抽象。本手册 Big Idea 1/3 章的知识点在这里全部"变现"。

                      课堂提交：三大组件与红线

                      Component A：Program Code（程序代码 PDF）

                      • 提交一个 PDF，包含全部程序代码（含注释）。
                      • 任何非本人（及合作者）写的代码——老师给的 starter code、API/开源代码、AI 生成的代码——必须在注释中注明出处（acknowledge + credit）。环境不支持注释时，可在文档编辑器里贴代码后补注释。
                      • 文本代码可 print 为 PDF；图形化（block-based）代码用截图贴入文档转 PDF，截图必须清晰、字号 ≥10pt。

                      Component B：Video（视频，独立完成）

                      项目要求
                      时长≤ 1 分钟
                      大小≤ 30MB
                      格式.webm / .mp4 / .wmv / .avi / .mov
                      必须展示① 程序的输入 ② 至少一个功能（functionality）③ 程序的输出
                      禁止出现任何能识别你个人身份的信息；语音旁白（可以用字幕）
                      协作不允许（代码可以与 partner 合作，视频不行）

                      Component C：Personalized Project Reference（PPR，独立完成）

                      PPR 是考试日的"开卷资料"，只含你自己写的两对代码截图（≥10pt、清晰、不得含任何注释）：

                      ① Procedure 部分（两段代码）

                      • 第一段：学生自开发过程（student-developed procedure），必须：
                      • 定义过程名与返回类型（如需要）；
                      • 包含并使用 ≥1 个对过程功能有实际影响的参数；
                      • 过程体内实现含 sequencing + selection + iteration 三结构的算法。
                      • 第二段：该过程在程序中被调用的位置。

                      ② List 部分（两段代码）

                      • 第一段：数据存入 list 的代码。
                      • 第二段：同一 list 的数据被使用的代码（由已有数据生成新数据、或访问多个元素），且是完成程序目的的一部分。

                      红线：PPR 不得包含 course content 或任何注释，违者 CPT 记 0 分（含考试日书面回答）；截止日前未提交 final，考试当天将没有 PPR 可用。事件处理器（event handler）、main 方法等内置/既有结构不算学生自开发过程。

                      学术诚信与 Generative AI 使用边界（CED 2023 新增，必读）

                      • Plagiarism = CPT 直接 0 分（连考试日的书面回答一起 0 分）：未经注明使用他人的代码、媒体、数据、信息，或 AI 生成的内容，都算。
                      • 允许的 AI 用法：理解编程概念、辅助开发、调试——视同同伴协作。
                      • 前提：你必须审查并完全理解与 AI 合写的代码；考试日会要求你详细解释自己的代码，解释不了就暴露了。
                      • 不得提交 AP Central 官方样例、课程供应商样例、或练习任务的作品作为最终提交。
                      • 提交时需在 AP Digital Portfolio 中三次 attestation（声明）遵守规则。

                      Program Requirements：程序六要素 checklist

                      CPT 程序本体必须包含以下六项学生自开发代码（官方 checklist，逐条自查）：

                      #要求常见不满足情形
                      1输入：来自用户（含触发事件的用户行为）/ 设备 / 在线数据流 / 文件 之一视频里看不到输入动作；输入写死在代码里
                      2至少一个 list（或其他集合类型）存储并使用数据，管理复杂度、服务于程序目的只用 len(list) 计数；数据从未被读取使用
                      3至少一个学生自开发过程：自定义名字、返回类型（如需要）、≥1 个参数过程无参数；用的是内置函数或事件处理器
                      4该过程体内实现含 sequencing、selection、iteration 的算法缺循环；缺分支；三种结构散落在过程外
                      5程序中调用该学生自开发过程只定义未调用；调用的是别的东西
                      6输出（视觉/听觉/文字/触觉）基于输入与程序功能产生输出与输入无关联

                      选题建议：程序规模不必大，但六要素要"一程序全占"。经典安全选题：测验/问答类、决策器类、数据统计类（含一个可以遍历的 list + 一个含三结构的过程）。避免：list 可被几个变量替代的伪抽象（见 §7）。

                      Q1 攻略：Program Design, Function, and Purpose（Row 3）

                      官方要求（3a，约 150 词，三小点全中才得 Row 3 这 1 分）：

                      • i. Describes the overall purpose of the program——程序为什么存在；
                      • ii. Describes what functionality of the program is demonstrated in the video——视频里演示了什么功能；
                      • iii. Describes the input and output of the program demonstrated in the video——视频里体现的输入与输出。

                      最高频丢分点（来自评分实践）：

                      1. 把 purpose 写成 function。Purpose 是"为谁解决什么/带来什么价值"，表达词库：entertainment / help the user … / lessen boredom / test the user's critical thinking skills / used to make decisions。Function 是"程序做了什么"。

                      2. 没有针对"视频里演示的功能"作答——答了程序全部功能却没扣住视频。

                      3. 输入输出没写、或写反（把输出当输入）。自查：输入 = 用户/设备给程序的；输出 = 程序给用户的。

                      官方样题（WR1 类别）：

                      Q1-Sample（官方 Prompt Category 样题 · Program Design, Function, and Purpose）

                      Identify an expected user of your program. Describe one way your program's design meets the needs of this user.

                      • 官方 Sample Response：The user of my game would be children who are trying to learn their colors in another language. The program design is great for children because each color button is filled with the corresponding color for the word. This will make it easy for students who don't know how to read to still use the app to hear the colors in languages.
                      • 点评：三句话三个采分点——第一句 Identify（谁用），第二句 Describe（哪个设计），第三句 Explain（为什么满足需求）。动词分层精准对应，没有一个废词。

                      Q2(a) 攻略：Algorithm Implementation（Row 4）

                      官方要求（3c.iv，约 100–200 词）：Explains in detailed steps how the algorithm implemented in the identified procedure works. Your explanation must be detailed enough for someone else to recreate it——详尽到别人能照着重新写出这段代码。

                      满分四步模板（把你的过程讲成"可复现食谱"）：

                      1. Initialize：哪些变量被创建、初值是什么；

                      2. Iterate：循环怎么跑、遍历什么、边界在哪；

                      3. Branch：判断什么条件、真/假各执行什么；

                      4. Result：循环/过程结束时结果是什么、怎么返回或输出。

                      官方样题一（WR2(a) 类别 · 迭代执行次数 + 死循环）：

                      Q2a-Sample1（官方 Prompt Category 样题 · Algorithm Development）

                      Consider the first iteration statement included in the Procedure section of your Personalized Project Reference. Identify the number of times the body of your iteration statement will execute. Describe a condition or error that would cause your iteration statement to not terminate and cause an infinite loop. If no such condition or error exists, explain how the loop could be modified to cause an infinite loop.

                      • 官方样例代码：for (int i : listOfValues) { System.out.println(i); }
                      • 官方 Sample Response：The loop iterates for each element in listOfValues. An infinite loop is not possible since this for-each loop iterates over all the elements of the list. If the list does not contain any elements, it would iterate 0 times.
                      • 点评：三问三答——执行次数（每元素一次）、是否存在死循环（for-each 不可能，理由充分）、若不存在就说明怎么改才会死循环（本题回答以"0 次"收尾补足 Identify）。注意"at least once"类问法的判据是 list 非空，不是"至少 2 个元素"。

                      官方样题二（WR2(c) 类别 · 用给定过程写计数算法）：

                      Q2a-Sample2（官方 Prompt Category 样题 · Data and Procedural Abstraction）

                      Suppose you are provided with a procedure called isEqual (value1, value2). The procedure returns true if the two parameters value1 and value2 are equal in value and returns false otherwise. Using the list you identified in the List section of your Personalized Project Reference, explain in detailed steps an algorithm that uses isEqual to count the number of times a certain value appears in your list. Your explanation must be detailed enough for someone else to write the program code.

                      • 官方 Sample Response：
                      • 1. Set a counter variable count to 0.
                      • 2. Iterate over the elements of the list named myList.
                      • 3. For each element, call isEqual to compare the element from myList to the given value. If isEqual returns true, add 1 to count.
                      • 4. After iterating over every list value, print the value of count.
                      • 点评：这就是"详细到别人能写出代码"的标准姿势——初始化 → 遍历 → 分支调用给定过程 → 输出结果，每一步都有变量名、有动作、有顺序。反面案例是只写"遍历列表，统计相等的个数，输出"——步骤缺失，无法重现，Row 4 直接 0 分。

                      丢分点：描述不够详细、无法支撑重现（官方反面案例原文：There are not enough details described to support others to rebuild the code of the procedure）。策略：在字数内写满步骤，变量名用你代码里的真名。

                      Q2(b) 攻略：Errors and Testing（Row 5）

                      官方要求（3d，约 200 词，三点全中才得这 1 分）：

                      • i. Describes two calls to the procedure identified in written response 3c. Each call must pass a different argument(s) that causes a different segment of code in the algorithm to execute（两次调用实参不同，且走到算法的不同代码段）；
                      • ii. Describes what condition(s) is being tested by each call；
                      • iii. Identifies the result of each call。

                      Argument（实参）vs Parameter（形参）——本小问第一概念坑：

                      Parameter 形参Argument 实参
                      出现场合声明过程时调用过程时
                      本质过程内部使用的变量传给过程的具体值（可以是变量中存的值）
                      int k = 5;
test(k);                     // k 是实参（调用处）
public void test(int a) {    // a 是形参（声明处）
    for (int i = 0; i < a; i++) {
        System.out.println(i);
    }
}

                      两次调用标准句式（照抄骨架，换成你的过程）：

                      First call: calculate_diversity(area_1) where area_1 = [3, 5, 11, 6]. Condition tested: whether the computed diversity value is ≥ 0.5. Result: 0.72 ≥ 0.5, so the program outputs "high".

                      Second call: calculate_diversity(area_2) where area_2 = [81, 2, 2, 2, 2]. Condition tested: the same threshold with a low-diversity list, taking the < 0.5 branch. Result: 0.17 < 0.5, so the program outputs "low".

                      官方样题（WR2(b) 类别 · 运行时错误）：

                      Q2b-Sample（官方 Prompt Category 样题 · Errors and Testing）

                      Consider the procedure included in part (i) of the Procedure section of your Personalized Project Reference. Describe a change to your procedure that will result in a run-time error. Explain why this change will result in a run-time error.

                      • 官方样例代码：Procedure printNums (int stop) { for (int i = 1; i <= stop; i++) { System.out.println(i); } }
                      • 官方 Sample Response：A run-time error would occur if instead of printing i, we printed i / 0, since this would cause a divide by 0 error.
                      • 点评：Describe（改哪里：打印 i / 0）+ Explain（为什么：除以零在运行时崩溃）。一改一因，两句拿满。其他可选答案：访问越界下标、对非数字输入做算术等——运行时错误 ≠ 语法错误，别答"少个分号"。

                      丢分点（评分实践原话级总结）：① 没写具体实参是什么（只说"传入不同值"）；② 两次调用的实参走的是同一段代码（哪怕结果不同也 0 分）；③ 把"调用后条件判断的结果"当成了"条件本身"来描述。可用测试策略（其他小问会考）：hand tracing、可视化、debugger、加输出语句、注释掉若干行。

                      Q2(c) 攻略：Data and Procedural Abstraction（Row 6）

                      Q2(c) 一道题同时覆盖数据抽象、管理复杂度、过程抽象三组判据，是分值最密的小问，也是"伪抽象"的重灾区。

                      Row 6 之 Data Abstraction：list 的存储与使用（3b.i–iv）

                      要求粘贴两段代码 + 文字回答四点：

                      • i. 数据如何存入 list 的代码（含声明）；
                      • ii. 同一 list 的数据被使用的代码（生成新数据或访问多元素，服务程序目的）；
                      • iii. Identify list 的名字；
                      • iv. Describe list 里的数据在程序中代表什么。

                      官方反面案例：只用了 list 的长度而没用里面的数据（Just use the length of the list, not the data in the list）；代码里没有体现 list 的创建与元素初始化。

                      Row 6 之 Managing Complexity：list 如何管理复杂度（3b.v）

                      官方要求：解释为什么不用这个 list 程序就写不出来 / 或者写出来会怎样不同。

                      满分句式骨架：

                      The list [名字] stores [存什么]. Without the list, I would need to [替代方案：为每个元素单设一个变量 / 复制粘贴 N 段重复代码]. For example, [具体例子]. This would make the program [后果：longer / harder to maintain / less flexible — 新增数据要改代码，而 list 只需追加元素].

                      官方反面案例（全是 0 分卷真话）：

                      • 4 个常量就能替代的 list——根本没管理复杂度；
                      • 只实现计数功能、可用一个计数变量替代的 list；
                      • 前文说 list A、后文说 list B——前后不一致；
                      • 写得太笼统（"列表让程序更简单"），没有结合自己程序里的代码说清"没有它会怎样"。

                      Row 6 之 Procedural Abstraction：过程与调用（3c.i–iii）

                      要求粘贴两段代码（过程定义 + 调用处）+ 文字回答：

                      • i. 过程：有名字、返回类型（如需要）、参数对功能有实际影响、过程体内实现三结构算法；
                      • ii. 调用处代码；
                      • iii. Describe 过程一般做什么 + 它如何为程序整体功能做贡献（不能只孤立讲过程本身）。

                      官方反面案例：过程缺参数（The procedure lacks parameters）；缺循环结构（Lack of loop structure）；没描述对整体程序的贡献（The contribution of procedure to the overall program functionality is not described）。

                      两个高频变式（3 套 Practice Exam 里的 2(c) 问）

                      5 分范文精读

                      下面是一份真实的 5 分考生书面回答（物种多样性计算器，Python），按 2023 卷编号 3a–3d 作答。2024 起映射：3a → 考试日 Q1（Row 3）；3b → Q2(c) 的数据抽象与复杂度判据（Row 6）；3c → Q2(a)（Row 4）与 Q2(c) 的过程抽象判据（Row 6）；3d → Q2(b)（Row 5）。作答实质不变，只是从"随作品提交"改到了"考试日限时作答"。

                      3.a.i. The purpose of the program is to help researchers save time and enable them to attribute more time to doing experiments or searching papers. Moreover, this program helps people know more about which types of ecosystems usually have high species diversity and how the species diversity value is calculated.

                      3.a.ii. The function of the program is to help people determine species diversity in an ecosystem based on number of animals of each species they collected from two areas in that ecosystem. This program estimates if both the two areas have high diversity, only one area has high diversity, or neither the two areas have high diversity. Finally, the diversity of the ecosystem is defined as high, moderate, or low, corresponding to the diversity of two areas.

                      3.a.iii. Input is two lists of the number of animals of each species in two researched areas of the ecosystem, and each number is separated by space. An example of input for a researched area is 3 5 11 6. Output is the species diversity value of two researched areas, the species diversity of two researched areas which is either "high" or "low", and the species diversity of the ecosystem, which is defined as "high", "moderate", or "low". …

                      • i 用"help researchers save time…"句式开门见山给 purpose（给谁、省什么），完全避开"把功能当目的"的坑；
                      • ii 用 "The function of the program is…" 明示切题，且只讲视频演示的功能（判定两个区域多样性 → 汇总生态多样性等级）；
                      • iii 输入输出各给具体样例（3 5 11 6），并完整枚举三种输出情形——阅卷人不需要猜。三小问一问不缺，Row 3 满分。

                      3.b.v. The use of list area_1 and area_2 in the program reduces complexity of my program code. Because the number of species in every area is different, by using a list, users could input different numbers of species in each area and apply a unified formula to every element in the list to calculate the species diversity of the researched area conveniently without changing any code. Therefore, this program could have higher extensibility. However, without a list, I need to set a lot of variables to store the different number of species of each area, which is time-consuming; I would have to name every single variable, which would be difficult to come up with all the names for each variable and increases the chance of spelling errors; I also need to change the statement for calculation of species diversity of the researched area, which makes the program more likely to have error.

                      • 完整走完"没有 list 会怎样"三连：要建一大堆变量（时间成本）→ 命名负担与拼写错误（可维护性）→ 公式代码要跟着改（扩展性）。
                      • 关键是"替代方案具体且可信"（官方判据：without-list 方案必须 plausible）——它不是空喊"会麻烦"，而是给出"逐物种建变量"这个真实可行的替代写法并论证其代价。

                      3.c.iii. The procedure calculate_diversity uses the list area as a parameter to calculate the species diversity of a particular area. First, it calculates the species diversity value by using the formula 1-Σn(n-1)/(N(N-1)) (This formula comes from https://www.statisticshowto.com/simpsons-diversity-index/) and rounds the value to two decimals. Then, diversity is compared with 0.5. If it is larger or equal to 0.5, it means the area has high diversity. If it is smaller than 0.5, it means the area has low diversity. Thus, this procedure judges the diversity of areas in the ecosystem.

                      3.d.i. First call: area_1 = [3, 5, 11, 6]; calculate_diversity(area_1) Second call: area_2 = [81, 2, 2, 2, 2]; calculate_diversity(area_2)

                      3.d.ii. Condition(s) tested by first call: The first call tests the situation that the species diversity of the researched area is high. … Because the value is larger or equal to 0.5, the species diversity of area1 is high. Condition(s) tested by second call: The second call tests the situation that the species diversity of the researched area is low. … Because the value is less than 0.5, the species diversity of area2 is low.

                      3.d.iii. Results of the first call: high. Results of the second call: low.

                      • 3c.iii：先一句话定位过程（用什么参数算什么），再按执行顺序复述（算值 → 四舍五入 → 与 0.5 比较 → 两个分支各自输出什么），最后回到"在整体程序中的角色"（judges the diversity of areas）——Describe + 贡献双达标。
