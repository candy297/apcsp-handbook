          APCSP 备考手册 · Big Idea 4 计算机系统与网络（Computer Systems and Networks）

          本章定位

          考试权重：11–15%（五个 Big Idea 中最轻，但全是"送分概念题"——前提是术语过关）。

          Big Idea 4 只含 3 个 Topic，是全书体量最小的一章，却是术语密度最高的一章：

          Topic名称EK 编码AP Classroom 题量核心任务
          4.1The InternetCSN-1.A ~ CSN-1.D20 题解释计算系统/网络如何工作（Skill 5.A）
          4.2Fault ToleranceCSN-1.E15 题评估容错方案（Skill 1.D）
          4.3Parallel and Distributed ComputingCSN-2.A / CSN-2.B6 题比较/计算方案效率（Skill 1.D）

          本章三大高频题型（CED 官方"Preparing for the AP Exam"原文点名）：

          1. 网络图分析题——给出设备连线图，问"信息如何从 A 传到 B""断几条线后无法通信""哪种配置有冗余路由"；

          2. 进程分配计算题——给出各进程耗时表，算并行执行的最短时间/节省时间/speedup；

          3. 概念辨析题——packet/metadata/protocol/bandwidth/redundancy 等术语的"best explains / best describes"四选一。

          与 Big Idea 5（Impact of Computing）经常联动出题（如网络安全、数字鸿沟），复习时建议连着看。

          Topic 4.1 The Internet（互联网）

          知识点梳理（CSN-1.A ~ CSN-1.D 逐条）

          CSN-1.A：解释计算设备如何在网络中协作

          • CSN-1.A.1 computing device（计算设备）：能运行程序的物理实体——计算机、平板、服务器、路由器、智能传感器。
          • CSN-1.A.2 computing system（计算系统）：为共同目的协同工作的一组计算设备和程序。
          • CSN-1.A.3 computer network（计算机网络）：一组互联的、能收发数据的计算设备。
          • CSN-1.A.4 计算机网络是计算系统的一种。
          • CSN-1.A.5 path（路径）：发送方到接收方之间直接相连的设备序列。
          • CSN-1.A.6 routing（路由）：寻找从发送方到接收方路径的过程。
          • CSN-1.A.7 bandwidth（带宽）：固定时间内能发送的最大数据量。
          • CSN-1.A.8 带宽通常以 bits per second（比特/秒） 计量。

          CSN-1.B：解释互联网如何工作

          • CSN-1.B.1 Internet（互联网）= 互相连接的网络的网络，使用标准化、开放（非专有）的通信协议。
          • CSN-1.B.2 接入互联网的前提：能把设备连到一台已联网的设备上。
          • CSN-1.B.3 protocol（协议）：约定好的规则集合，规定系统的行为。
          • CSN-1.B.4 互联网协议是开放的 → 用户可以方便地接入新设备。
          • CSN-1.B.5 互联网上的路由通常是动态的，不预先指定。
          • CSN-1.B.6 scalability（可扩展性）：系统改变规模以满足新需求的能力。
          • CSN-1.B.7 互联网从设计之初就是可扩展的。

          CSN-1.C：解释数据如何以包的形式经互联网发送

          • CSN-1.C.1 信息以 data stream（数据流）的形式经互联网传递；数据流包含被封装进 packet（数据包） 的数据块。
          • CSN-1.C.2 每个包 = 一块数据 + metadata（元数据）；元数据用于路由（origin → destination）和重组（reassembly）。
          • CSN-1.C.3 包可能按序、乱序或根本不到达目的地。
          • CSN-1.C.4 IP、TCP、UDP 是互联网常用协议。

          CSN-1.D：区分互联网与万维网

          • CSN-1.D.1 World Wide Web（万维网）= 相互链接的网页、程序和文件的系统。
          • CSN-1.D.2 HTTP 是万维网使用的协议。
          • CSN-1.D.3 万维网使用互联网（WWW 是互联网上的一种服务，不是互联网本身）。

          重难点

          ① 包交换（packet switching）——必考核心

          • 大文件被拆分成多个包，每个包独立路由，可能走不同路径（CSN-1.C.3 + CSN-1.B.5）；
          • 接收方设备用包里的 metadata 重组出原始文件；
          • 对照：电路交换（circuit switching）需要先建立专用线路——互联网不用这种方式。

          ② 开放协议 ⇄ 可扩展性（因果链）

          开放/标准化、非专有的协议 → 任何厂商的设备都能按同一套规则通信 → 新设备容易加入 → 网络可扩展（scalable）。这条因果链在 2025 Q41、APC 4.1-Q13/Q14/Q20 反复考。

          ③ bandwidth 的操作性定义

          带宽 = 单位时间（秒）能传输的最大比特数。题目问"如何验证带宽提高了"，答案永远是"测平均每秒传输的比特数"（见 2025 Q19）。

          易错点

          易错点正确认识
          "包按指定顺序沿同一路径发送"❌ 包可走不同路径、可乱序到达、可能不到达
          "packet metadata 含加密密钥/冗余副本/加密指令"❌ metadata 只用于路由 + 重组（2026 Q37 三个干扰项全是这个套路）
          WWW 与 Internet 混同WWW 是"链接页面/程序/文件"的系统，Internet 是"网络的网络"；WWW 用 Internet
          "每台联网设备都会获得数字证书"❌ 是 IP address（证书与身份验证有关，不是联网必发）
          "新设备接入需要厂商专有协议"❌ 开放协议正是为了跨厂商通信
          bandwidth 与"文件数量/设备数量/连接数"带宽只看每秒比特数
          IETF 的职能制定互联网标准与协议（不是版权、杀毒、密钥验证）

          Topic 4.2 Fault Tolerance（容错）

          知识点梳理（CSN-1.E）

          • CSN-1.E.1 互联网被设计为容错的，对路由和数据传输做了抽象。
          • CSN-1.E.2 redundancy（冗余）= 加入额外组件，在其他组件失效时缓解系统故障。
          • CSN-1.E.3 实现网络冗余的一种方式：任意两台互联设备之间有多于一条路径。
          • CSN-1.E.4 若某设备或连接失效，后续数据将改走其他路径（如果存在）。
          • CSN-1.E.5 系统能在故障发生时仍继续工作，称为 fault-tolerant（容错）。复杂系统的组件常在意料之外的时刻、甚至成组地失效，容错让用户能继续使用网络。
          • CSN-1.E.6 冗余通常需要额外资源，但换来容错的好处。
          • CSN-1.E.7 两点间路由选项的冗余提高了互联网的可靠性，并帮助其扩展到更多设备和人群。

          重难点：网络图题三步法

          网络图题（APC 4.2 有 7 道）看似吓人，其实全部是同一套动作：

          1. 数路径：在图上列出从 X 到 Y 的所有不重复路径；

          2. 找"断点"：问"最少断几条连接后 X、Y 无法通信"= 找最小割——把 X、Y 分离必须破坏的连接数；若只有一条必经之路（桥），答案就是 1；

          3. 判断冗余：任意两点间有 ≥2 条不相交路径 → 有 redundant routing → 容错。

          注意：APC 4.2 的 Q1/Q6/Q7/Q9/Q10/Q11/Q12/Q13/Q14/Q15 均依赖图形，纸面练习必须对着原书图做；本手册精选了纯文字的 Q2/Q3/Q4/Q5/Q8，图形题请配合原 PDF 训练。

          易错点

          易错点正确认识
          "加密/压缩/数字证书能提高容错"❌ 容错只靠冗余路径（2026 Q23：答案 D）
          "容错保证组件永不故障"❌ 容错 = 组件故障后系统仍能工作
          "冗余是免费的"❌ 需要额外资源（CSN-1.E.6），好处换代价
          "容错 = 传输更快"❌ 容错管可靠性，不管速度
          "中心计算机监控整个互联网"❌ 互联网是分布式的，没有中央监控（APC 4.1-Q7 选项 I 错）

          Topic 4.3 Parallel and Distributed Computing（并行与分布式计算）

          知识点梳理（CSN-2.A / CSN-2.B）

          CSN-2.A：比较方案、确定效率

          • CSN-2.A.1 sequential computing（顺序计算）：操作按顺序一次一个执行。
          • CSN-2.A.2 parallel computing（并行计算）：程序被拆成多个较小的顺序操作，其中一些同时执行。
          • CSN-2.A.3 distributed computing（分布式计算）：用多台设备运行一个程序。
          • CSN-2.A.4 比较效率：完成同一任务所花的时间。
          • CSN-2.A.5 顺序解的耗时 = 所有步骤之和。
          • CSN-2.A.6 并行解的耗时 = 顺序任务 + 最长的那个并行任务。
          • CSN-2.A.7 speedup（加速比）= 顺序耗时 ÷ 并行耗时。

          CSN-2.B：并行/分布式的收益与挑战

          • CSN-2.B.1 并行计算 = 并行部分 + 顺序部分。
          • CSN-2.B.2 并行解比顺序解更可扩展。
          • CSN-2.B.3 分布式计算能解决单机因处理时间或存储限制无法解决的问题。
          • CSN-2.B.4 分布式计算能更快解决大得多的 problem。
          • CSN-2.B.5 增加并行部分后，效率仍受顺序部分限制——加到某一点后，继续并行不再显著提升效率。

          重难点：进程分配计算题的标准算法

          两类处理器、若干独立进程，求最短时间：

          1. 顺序时间 = 所有进程时间相加；

          2. 并行时间：把进程分给两个处理器，使两个处理器中较忙的那个的 总时间 尽量小；

          3. 经验口诀：先排最长的任务，再让两个处理器负载均衡；

          4. 常见问法换算：

          • "最短并行时间" = 较优分配下较长一链的耗时；
          • "并行比顺序节省多少" = 顺序时间 − 并行时间；
          • "speedup" = 顺序时间 ÷ 并行时间。

          例（APC 4.3-Q3，W20/X30/Y45/Z50）：C 选项 W+Z=70、X+Y=75 → 最长链 75 秒，是四种分配中最小的 → 答案 C。

          例（APC 4.3-Q6，P30/Q10/R20/S15）：A 选项 P+Q=40、R+S=35 → 最长链 40 秒，最短 → 答案 A。

          易错点

          易错点正确认识
          "任何顺序问题都能用并行降到约一半时间"❌ 受顺序部分限制（CSN-2.B.5）
          "并行能解 undecidable 问题"❌ 可判定性与算力无关（联动 Big 3 的 3.18）
          "处理器越多效率一直提升"❌ 收益递减，顺序部分封顶（2026 Q28 考的正是这句话）
          "每步依赖上一步输出的算法适合并行"❌ 强依赖链只能顺序执行（APC 4.3-Q2）
          speedup 无上限speedup = 顺序÷并行，最大也就顺序时间 ÷（顺序部分 + 最长并行任务）
          忽略"任一处理器可跑任一进程、一进程只能跑在一个处理器上"这是所有计算题的隐含前提，读题先圈出来

          考前速查表

          1. 计算设备能跑程序；网络 = 互联可收发数据的设备；路径 = 直连设备序列；路由 = 找路径。

          2. 带宽 = 每秒最大比特数（bits per second）。

          3. Internet = 网络的网络 + 开放标准协议；协议 = 约定好的规则。

          4. 互联网路由动态、不预定；设计上可扩展。

          5. 包 = 数据块 + metadata；metadata 用于路由和重组，与加密无关。

          6. 包可乱序、可丢失；接收方负责重组。

          7. IP / TCP / UDP 是三大常用协议；HTTP 属于 WWW。

          8. WWW = 链接的页面/程序/文件系统；WWW 用 Internet，但不是 Internet。

          9. 冗余 = 备用组件/多余路径；两点间多条路径 → 容错。

          10. 容错 = 出故障仍能继续工作；代价是额外资源。

          11. 断线后数据改走其他可用路径。

          12. 顺序时间 = 步骤之和；并行时间 = 顺序部分 + 最长并行任务。

          13. speedup = 顺序时间 ÷ 并行时间。

          14. 并行收益受顺序部分限制；加处理器收益递减。

          15. 并行适合相互独立的子任务；强依赖链不适合。

          16. 分布式 = 多设备协作，能解单机（时间/存储）解不了的问题。

          17. 容错 ≠ 安全：加密/证书/压缩都不提高容错。

          18. 网络图题：先数路径，再找最小割，两点间 ≥2 条路径才有冗余路由。

          国际考真题与解析

          以下题目均转录自工作区英文原卷（题干与选项为原文），解析为中文。可点击选项作答。

          CED 官方样题（2023 CED）

          Q12（官方考点：CSN-2.A.b · Skill 1.D ）

          A certain computer has two identical processors that are able to run in parallel. Each processor can run only one process at a time, and each process must be executed on a single processor. The following table indicates the amount of time it takes to execute each of three processes on a single processor. Assume that none of the processes are dependent on any of the other processes.

          ProcessExecution Time on Either Processor
          X60 seconds
          Y30 seconds
          Z50 seconds

          Which of the following best approximates the minimum possible time to execute all three processes when the two processors are run in parallel?

          • A60 seconds
          • B70 seconds
          • C80 seconds
          • D90 seconds
          点击选项作答，选后显示正确答案与解析

          正确答案：C

          。两个处理器：X（60 秒）单独一个，Y+Z 顺序在另一个（30+50=80 秒）。并行总时长 = 较长一链 = 80 秒。其他分法：X+Y=90 / Z=50 → 90；X+Z=110 / Y=30 → 110；都不如 80。与 AP Classroom 4.3-Q5 完全同题——官方向来爱重复自己的题。

          2025 补充练习卷（Supplemental Practice Exam MCQ）

          Q6（考点：CSN-1.C.1/1.C.2/1.E.4 ）

          An Internet user requests a large file from an online media storage website. Which of the following best describes how the file is transmitted to the user?

          • AA compressed version of the file is encapsulated in a single packet that contains metadata used by the recipient's device to decompress the file.
          • BAn encrypted version of the file is encapsulated in a single packet that contains a key used by the recipient's device to decrypt the file.
          • CThe file is broken into packets that contain reassembly metadata, and these packets are routed along potentially different paths and reassembled by the recipient's device using the metadata.
          • DThe file is tagged with descriptive metadata and then routed to the recipient along a path designated exclusively for this type of file.
          点击选项作答，选后显示正确答案与解析

          正确答案：C

          。官方解析：包经冗余路由沿多条路径发送，路径不预定；每个包含文件的一部分和用于重组的 metadata。A/B 错在"单个包装下整个文件"，D 错在"专用路径"。

          Q13（考点：CSN-2.A.6/CSN-2.B.2 ）

          Which of the following best describes the performance benefit, if any, of parallel computing solutions compared to sequential computing solutions?

          • AParallel solutions have the ability to minimize the number of processors needed to solve problems that have a polynomial number of steps.
          • BParallel solutions have the ability to solve undecidable problems that cannot be solved using sequential solutions.
          • CParallel solutions typically offer improvement in overall execution time when a task can be broken into smaller tasks that can be performed simultaneously.
          • DParallel solutions typically have the same efficiency as sequential solutions because parallel solutions are limited by a sequential portion.
          点击选项作答，选后显示正确答案与解析

          正确答案：C

          。并行把任务拆成可同时执行的小任务 → 总执行时间改善。B 是经典陷阱：undecidable 与算力无关。D 过度引申"受顺序部分限制"——有限制不等于"效率相同"。

          Q19（考点：CSN-1.A.7/1.A.8 ）

          A company's Internet service provider announces that it is increasing the bandwidth of the company's network on July 1. Performing which of the following actions before and after July 1 would be most appropriate in verifying the increased bandwidth?

          • ACounting the number of connections between devices on the network
          • BCounting the number of devices connected to the network
          • CDetermining the average number of bits per second that can be transmitted between devices on the network
          • DDetermining the total number of files that are transmitted on the network on a given day
          点击选项作答，选后显示正确答案与解析

          正确答案：C

          。带宽的定义就是平均每秒可传输的比特数——前后各测一次直接验证。其余选项量的都不是带宽。

          Q36（考点：CSN-1.D.1 ）

          Which of the following best describes the World Wide Web?

          • AThe World Wide Web is another name for the network of interconnected networks known as the Internet.
          • BThe World Wide Web is the name for the set of protocols used to exchange information between devices connected to the Internet.
          • CThe World Wide Web is a system of linked pages and files that is accessed using the Internet.
          • DThe World Wide Web is a system used to identify users sending messages on the Internet.
          点击选项作答，选后显示正确答案与解析

          正确答案：C

          。WWW = 相互链接的页面和文件的系统，通过 Internet 访问。A 是最大陷阱——"WWW 就是 Internet 的别名"是错的。

          Q41（考点：CSN-1.B.1/1.B.4/1.B.7 ）

          Which of the following statements accurately describes how the Internet works?

          • AEach device manufacturer requires different proprietary protocols to connect devices to the Internet.
          • BInternet protocols are designed to ensure that intellectual property is distributed legally.
          • CInternet protocols are standardized and open, helping the network to be scalable.
          • DPackets are typically routed in such a way that their path on the network must be specified in advance.
          点击选项作答，选后显示正确答案与解析

          正确答案：C

          。互联网用标准化、开放（非专有）协议 → 设备容易加入 → 支持可扩展性。D 与"动态路由"直接矛盾。

          Q56（考点：CSN-2.A.5/2.A.6/2.A.7 ）

          题干背景（同卷上文）：A computer processor executes operations of a computer program. A certain computer has two processors that are able to run in parallel. The following table indicates the amount of time it takes either processor to execute each of two processes. Assume that neither process is dependent on the other.

          ProcessExecution Time on Either Processor
          F40 seconds
          G10 seconds

          Which of the following best approximates the amount of time saved by running the processes in parallel instead of running them sequentially?

          • A10 seconds
          • B30 seconds
          • C40 seconds
          • D50 seconds
          点击选项作答，选后显示正确答案与解析

          A certain computer has two identical processors that are able to run in parallel. The following table indicates the amount of time it takes to execute each of four processes on a single processor. Assume that none of the processes is dependent on any of the other processes.

          ProcessExecution Time on Either Processor
          P30 seconds
          Q10 seconds
          R20 seconds
          S15 seconds

          Which of the following parallel computing solutions would minimize the amount of time it takes to execute all four processes?

          • ARunning processes P and Q on one processor and processes R and S on the other processor
          • BRunning processes P and R on one processor and processes Q and S on the other processor
          • CRunning processes P and S on one processor and processes Q and R on the other processor
          • DRunning process P on one processor and processes Q, R, and S on the other processor
          点击选项作答，选后显示正确答案与解析

          正确答案：A

          。各分配的较长链：A → max(40, 35)=40；B → max(50, 25)=50；C → max(45, 30)=45；D → max(30, 45)=45。A 最短。

          Create PT 写作题中的 Big Idea 4

          Create PT 的书面回答不直接考 CSN 编码，但有两处天然联动，写作时可以借力：

          1. Row 3（实现中管理的数据）与模拟/仿真：如果你的程序模拟了网络/队列/多任务场景，可以在描述中说明"哪些部分是并行处理的、哪些必须顺序执行"，呼应 CSN-2.A；

          2. 创新影响类问题：描述计算创新时，涉及"系统依赖互联网基础设施/带宽/容错"的表述能让影响分析更具体（例如视频流服务依赖包交换与冗余路由）。

          注意：Create PT 程序本身不需要实现并行计算——AP 的伪代码与大多数学生语言（如 AP CSA 的 Java、Scratch 类图形语言）在这个考核点上只要求概念辨析。

          备考策略

          1. 术语卡片优先：本章 80% 的分数来自术语精确记忆——packet/metadata/routing/bandwidth/protocol/redundancy/scalability/fault-tolerant/sequential/parallel/distributed/speedup，每个术语用"一句定义 + 一个反例"记。

          2. 网络图题限时训练：APC 4.2 的 10 道图形题是同质题库，练 5 道后正确率会稳定；关键动作是"先在图上标出所有路径，再回答"。

          3. 进程分配题套路化：审题先圈三个条件——"two identical processors""each process must be executed on a single processor""none of the processes is dependent"，然后枚举选项算"较长链"，选最小。

          4. 警惕绝对化措辞：only / all / must / always / eliminates / limitless 出现的选项，在本章几乎必错（可扩展性、动态路由、无中心监控三条原则足以排除大多数干扰项）。
